# The Dalles Local Information Survey: explorer

Interactive explorer of the cleaned responses to the fall 2026 The Dalles Local Information Survey, run by University of Oregon journalism students (JCOM 430 Engaged Journalism, Agora Journalism Center) with the City of The Dalles.

Live page: https://drewvigal.github.io/dalles-survey-explorer/

The page is a single self-contained HTML file. Sticky notes left by visitors are stored in a Google Sheet through a small Apps Script web app. Responses are anonymous; bot and survey-farm traffic has been screened out (see the Method tab).
